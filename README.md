# Portfolio · Paula Falco

Sitio estático (un solo `index.html` + carpeta `img/`). No necesita build: se publica tal cual en Vercel.

## Estructura
- `index.html`: todo el sitio (HTML, CSS y JS en un solo archivo). Bilingüe ES/EN con el switch de arriba (`<span lang="es">` / `<span lang="en">`).
- `img/`: imágenes de los casos y la foto.

Pestañas: Inicio · Casos (01, 02, 03) · Más proyectos · Liderazgo · Sobre mí · Contacto.
Rutas por hash: `#inicio`, `#casos`, `#caso-01`, `#caso-02`, `#caso-03`, `#mas-proyectos`, `#liderazgo`, `#sobre-mi`, `#contacto`.

## Decisiones de contenido y diseño
- Paleta: fondo beige, tinta casi negra, acentos verde oliva. Tipografías: Inter Tight, Instrument Serif (itálica) y JetBrains Mono.
- Wording: nada autorreferencial (evitar "yo hice"); hablar del trabajo y del equipo.
- Liderazgo: basado en confianza y autonomía, con instancias de revisión que aseguran rigor metodológico. No usar "micromanagement".
- Posicionamiento: Service Design como puente hacia estrategia de experiencia, UX, CX y producto. No presentarse como "Product Manager" (cargo no ejercido formalmente); sí "Product Discovery & Strategy".
- Casos cortos, con cifras grandes e imágenes como evidencia del oficio (miniaturas con zoom opcional), no para leer todo el detalle.
- No usar métricas de otras personas ni datos internos sensibles. Sin nombres de terceros.
- Español: "backoffice" todo junto. Inglés: "back office" (sustantivo) / "back-office" (adjetivo).
- Modalidad: remoto o híbrido (Córdoba, Buenos Aires u otras ciudades).
